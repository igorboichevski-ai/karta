# Карта лесной отрасли Беларуси

Веб-карта лесхозов, лесничеств, пилорам и деревообрабатывающих предприятий с простой CRM для команды.

## Как устроено
- `index.html` — весь сайт (Leaflet + Supabase JS). Слои «Схема» (OpenStreetMap) и «Спутник» (Esri).
- `config.js` — адрес проекта Supabase и публичный ключ `anon`.
- `supabase/setup.sql` — схема базы и права доступа. Запускается один раз в Supabase → SQL Editor.
- Списки компаний в репозитории не хранятся: они только в базе (доступ после входа).

## Запуск
1. В Supabase выполнить `supabase/setup.sql`.
2. В Supabase → Authentication → Sign In / Providers отключить «Allow new users to sign up».
3. Сотрудников добавлять в Authentication → Users → Add user (почта + пароль, «Auto confirm»).
4. Сделать первого администратора: `update profiles set role = 'admin' where id = (select id from auth.users where email = '...');`
5. Вписать URL и ключ в `config.js`.

## На телефоне

Сайт устанавливается как приложение (PWA): иконка на рабочем столе, карта на весь экран.
- Android (Chrome): вкладка «Список» → кнопка «Установить на телефон», или меню ⋮ → «Установить приложение».
- iPhone (Safari): «Поделиться» → «На экран Домой».

Без интернета показываются точки с последней загрузки (хранятся в браузере, IndexedDB) и куски схемы OSM, которые уже открывались. Правки точек, комментарии, новые точки и визиты, сделанные без сети, ждут в очереди в браузере (localStorage) и уходят по порядку, когда появится связь; отправляются только изменённые поля. Удаление работает только с интернетом.

Файлы: `manifest.webmanifest`, `sw.js` (оболочка, библиотеки и просмотренные куски схемы), `icons/`.

## Источники данных
- Список лесхозов: Министерство лесного хозяйства (mlh.gov.by).
- Крупные предприятия: обзор «Деревообработка в Беларуси 2023» (investinbelarus.by).
- Пилорамы, производства, лесничества: © участники OpenStreetMap, лицензия ODbL.
- Границы областей и районов (`regions.geojson`): © участники OpenStreetMap, ODbL; выгрузка через Overpass, упрощены mapshaper до ~300 КБ.
- Кандидаты со спутника: ручной просмотр снимков Esri World Imagery, требуют проверки.
